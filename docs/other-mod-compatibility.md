# Compatibility with Other Mods
Compatibility is likely to be fairly mixed with other mods overall. It changes quite a few things and there is very real chances of conflicts. The most likely outcome is changes not working with the new buildings. I have added them all to the expected asset pools internally but it depends how other mods have been written to change things.

HINT: The following headers are links to the specific mod.

## [Community Bug Fix by Taludas](https://mod.io/g/anno-117-pax-romana/m/anno-117-pax-romana-community-bug-fix-mod)
This should be compatible. The main conflict is that it also changes the public building effects in Albion. I've set this mod to load after the community bugfix mod, which based on some quick testing allows everything to work properly.

## [Rocky, Patron of Construction by Jtmzac (me)](https://mod.io/g/anno-117-pax-romana/m/rocky-patron-of-construction)
I have added a little compatiblity patch that removes aqueduct support for granite quarries and changes the Albion Rocky shrine to use tiles to match this mod.
