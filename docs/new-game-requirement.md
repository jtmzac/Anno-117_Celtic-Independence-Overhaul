# New Game Requirement

I strongly, strongly recommend a new save when installing this mod. While it isn't technically required, there are so many changes that using it on an existing save is just not worth it.

## What happens if you do use it on an existing save?
The main thing that doesn't work at all on existing saves is removing the herb fertility from islands. Otherwise here's a non-exhaustive list of all the things that will require fixing:

* A lot of building effects will not be updated or work until you rebuild them.
* You will have at least a partial economy collapse because so many needs have changed.
* You will need to redo your city layouts to fit the new public service buildings and production chains.
* Roman-Celtic islands will need all the Celtic wader residences swapped to the new Roman-Celtic ones.
* Celtic farms and mines will all need to be changed to the new systems if you were using aqueducts.
* You will need to redo a lot of trade routes.
